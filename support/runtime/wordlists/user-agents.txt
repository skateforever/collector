#
# Selection criteria:
#   * No bot identifiers (Googlebot, Baiduspider, Bingbot, etc.) — those
#     get filtered or rate-limited by many WAFs and defeat the point.
#   * No headless / tool UAs (HeadlessChrome, curl, wget, python-requests,
#     PhantomJS) — same reason.
#   * Versions kept reasonably current (2023-2024). Very old browser UAs
#     are themselves a fingerprint of automated traffic.
#   * Mix of desktop (Windows / macOS / Linux) and mobile (iOS / Android),
#     weighted toward what real human traffic actually looks like.
#
# To customise: edit this file, or point collector_user_agents in
# collector.cfg at a different path.
