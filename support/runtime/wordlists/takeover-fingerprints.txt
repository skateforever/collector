# Subdomain takeover fingerprints loaded by scans/takeover.sh
# (takeover_match_provider). Lines starting with '#' and blank lines are
# ignored at load time, so section headers below cost nothing at runtime.
#
# Format (pipe-separated, three fields):
#   <cname_regex>|<provider_tag>|<body_fingerprint>
#
#   cname_regex       Extended regex (POSIX ERE) matched case-insensitively
#                     against the final hop of the resolved CNAME chain.
#                     Anchor with $ when the provider only owns one TLD;
#                     keep dots escaped (\.) to avoid wildcard surprises.
#   provider_tag      Short slug emitted into domains_takeover.txt.
#   body_fingerprint  Literal substring (passed to grep -F) expected in
#                     the HTTP response body when the resource is
#                     unclaimed. Leave empty for providers that don't
#                     return a stable error string — the matcher will
#                     still classify the host as MEDIUM via the CNAME but
#                     won't be able to upgrade it to STRONG via HTTP.
#
# Reference / origin of these patterns:
#   https://github.com/EdOverflow/can-i-take-over-xyz
#   https://github.com/projectdiscovery/nuclei-templates/tree/main/http/takeovers
#
# Keep this list in sync with can-i-take-over-xyz — providers add and
# remove takeover vectors regularly (Heroku, GitHub Pages and Azure have
# all tightened verification at various points). When a provider is no
# longer exploitable, comment the line out rather than deleting it so
# the diff stays readable.
